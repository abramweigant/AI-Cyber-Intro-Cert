# AI-Cyber Intro Certification — public repository

This is the **public, student-facing** repository: the seven student notebooks, the datasets
they load, `setup.sh`, `requirements.txt` / `requirements.lock`, `README.md`, `GRADING.md`,
and the model-server gateway in `server/`.

**The working context for this course is not in this repository.** It lives in the private
instructor repository, `abramweigant/AI-Cyber-Intro-Cert-Instructor`, as `CLAUDE.md`. It is
kept there because it records the solutions, the reference figures students are asked to
predict, and the surprise each module is built around.

If that repository is checked out, read its `CLAUDE.md` before changing anything here. It is
found in one of two places, and Claude Code imports whichever exists:

@instructor/CLAUDE.md
@../AI-Cyber-Intro-Cert-Instructor/CLAUDE.md

## Rules that apply even without the private repository

- **Nothing that gives away an answer goes in this repository**: no solutions, no instructor
  notes, no PDF renders of instructor notebooks, no reference results for tasks that ask
  students to predict. `.gitignore` guards `instructor/` and `*.pdf`; do not remove those lines.
- **Do not hand-edit a student notebook on its own.** Each one is paired with an instructor
  copy, cell for cell, and Modules 4 and 6 are generated by builder scripts in the private
  repository. An edit made only here will be overwritten or will break the pairing.
- **Datasets are loaded by URL from this repository** through the `DATA_URL` constant in each
  notebook's setup cell. Do not move, rename or hardcode them.
- `.env` holds the model server's address for Module 6 and is never committed.
